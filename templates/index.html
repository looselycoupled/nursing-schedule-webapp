    Set up iOS timer button
    1. Open the Shortcuts app on your iPhone.
    2. Create a new shortcut named exactly Start Feeding Timer.
    3. Tap the ⓘ details button up top and set Accept to Text.
    4. Add one action: Start Timer.
    5. In that action's Duration field, delete the default 5, then tap the variable pill above the keyboard (or type @) and insert Shortcut Input. Duration should now be a colored pill, not a typed number.
    6. Set the unit next to Duration to Minutes and save.
    7. Test it: open Safari and paste shortcuts://run-shortcut?name=Start%20Feeding%20Timer&input=text&text=42 — you should get a 42-minute timer.

    If the timer always runs for 5 minutes, the Duration field still holds the default number rather than the variable.
